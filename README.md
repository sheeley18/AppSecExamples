## Vulnerabilities Included

### 1. Cross-Site Scripting (XSS)

**Reflected XSS:**
- Endpoint: `GET /search?q=<script>alert('XSS')</script>`
- User input is directly embedded in HTML response without sanitization

**Stored XSS:**
- Endpoints: `POST /comment` and `GET /comments`
- User-submitted comments are stored and rendered without sanitization

### 2. SQL Injection

**Login Bypass:**
- Endpoint: `POST /login`
- Payload example: `username: admin' OR '1'='1' --`
- SQL query uses string concatenation instead of parameterized queries

**Data Extraction:**
- Endpoint: `GET /users/search?term=<payload>`
- Allows arbitrary SQL execution through search parameter

### 3. Null Dereference

**Profile Access:**
- Endpoint: `GET /profile/:userId`
- No null check on database query result
- Crashes when accessing non-existent user

**Settings Update:**
- Endpoint: `POST /update-settings`
- No validation on nested object properties
- Crashes when required properties are missing
